# Estética Auto

Protótipo PWA de um sistema interno de gestão para estética automotiva.

## Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- vite-plugin-pwa

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite, normalmente `http://localhost:5173`.

## Gerar build de produção

```bash
npm run build
npm run preview
```

O PWA é gerado no build de produção e pode ser instalado quando publicado em HTTPS.
